# Third-Party Awesome-List Directory Maintenance

This project does not submit or maintain directory listings in external third-party "awesome" lists (such as `awesome-ai-plugins`).

## Why this is out of scope

The maintainers keep the project's external directory and marketing footprint intentionally minimal. Maintaining third-party directory entries creates ongoing chore overhead (broken links, stale project descriptions, and submission policy compliance across multiple external repositories) without providing direct value to users who discover and install the plugin through OpenCode's ecosystem or the official repository.

Community members are welcome to link to or mention `oh-my-opencode-slim` in their own curated lists, but the project does not officially maintain or open pull requests to external list repositories.
